三種實作方案

選擇前端 UI 庫與架構策略

推薦

方案 A — CoreUI React (@coreui/react)

優點

  • 與 NeuVector 最接近，CSSidebar 多層導覽開箱即用
  • 深色 Sidebar + 淺色 Content 主題內建
  • Bootstrap 5 CSS 加持，表格/表單樣式一致

缺點

  • 需完整替換 Ant Design 所有元件
  • 多一個 @coreui 依賴

方案 B — React-Bootstrap 自建

優點

  • 依賴最輕，只有 react-bootstrap + bootstrap CSS
  • Sidebar/Header 完全自訂，無框架限制

缺點

  • Sidebar collapse、多層選單需自行實作
  • 實作時間較長，視覺一致性靠自己維持

方案 C — 混合 (Ant Design + Bootstrap Shell)

優點

  • 保留 Ant Design Table/Form（已測試穩定）
  • 只換最外層 Layout shell，改動範圍最小

缺點

  • 兩套 CSS 系統並存，易有衝突
  • 視覺一致性難以做到真正的 NeuVector 感

推薦方案 A（CoreUI React），與 NeuVector 風格最接近且開發效率最高
